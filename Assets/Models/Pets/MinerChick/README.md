# DigPals Miner Chick

Pet anak ayam dengan tubuh bulat, sayap kecil, kaki oranye, helm dan lampu tambang.

`DigPals_MinerChick.blend` berisi model, rig, material dan tiga action. Impor `DigPals_MinerChick_Rig.fbx` melalui Roblox Studio 3D Importer, lalu impor file FBX dalam `Animations` untuk rig yang sama. Idle dan walk dibuat untuk loop; digging sekali putar. Animasi dibuat pada 24 FPS.

Model terdiri dari satu skinned mesh, 11 bones, 7.274 vertices dan 7.800 polygons. Dimensi Blender sekitar 0,651 × 0,829 × 0,765 meter, atau kira-kira 2,32 × 2,96 × 2,73 studs pada konversi 3,571 studs per meter. Di Blender model menghadap -Y dengan +Z ke atas; FBX menggunakan Forward -Z dan Up Y. Pedestal dan lampu preview tidak termasuk ekspor.

Keempat FBX telah diimpor ulang di Blender dan mesh, armature, material, bones serta rentang animasi terdeteksi. Lihat `validation.json`. Pemeriksaan visual dan playback di Roblox Studio masih diperlukan; tampilan material dapat berbeda. Tidak ada aset yang dipublikasikan.

Skrip build dan validasi menggunakan skrip pendamping di folder `CometMinerDog`; pertahankan kedua folder untuk menjalankan ulang skrip.
