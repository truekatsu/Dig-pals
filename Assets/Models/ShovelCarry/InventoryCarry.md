# Inventory hotbar and egg placement

Items, Eggs and Pet cards assign and equip a server-owned shortcut in slots 4–9. The first empty slot is used; a full bar replaces slot 9. Re-selecting an already assigned object uses its current slot. Assigning/replacing shortcuts never removes inventory ownership. Keys 4–9 and clicking/tapping a slot equip or stow the object. Slots 1–3 retain shovel and menu controls. Shortcuts survive character respawn within the current server session.

CarryHotbarService validates ownership on every assignment/equip, removes depleted shortcuts and identifies individual egg entries without relying on shifting array indexes after assignment. CarryModelBuilder shares models between equipped Tools and viewport previews. Existing EggAssets/EggModels and their materials are used; items and pets use native primitive models. All held parts are massless and have collision/touch/query disabled. The shared shovel carry remains unchanged.

The old IncubatorGui and tutorial BUKA TELUR button are no longer created/shown. Holding an egg enables a cursor preview and click placement on PC; mobile uses a tap on the player's base. EggPlacementService validates the assigned plot, ground bounds, distance, overlap, ownership and configured base egg capacity before consuming one egg. Placement saves local ground X/Z in the existing Incubators entry, with ReadyAt retaining the incubation timer. Placed eggs show the timer and expose a proximity Hatch action when ready. Existing quest, discovery and tutorial hatch events remain connected.

Verified in Studio: Items/Eggs/Pet assignment, ordered fill 4–9, replacement at 9 without inventory loss, actual inventory Eggs card click, hotbar selection/stow, invalid ownership/slot rejection, 3D pet Tool, own-base cursor placement, outside-base rejection, mobile simulator placement, saved local position, countdown and ready egg hatching into an owned pet. Temporary profiles and test items were restored. Studio returned to Edit/default viewport; no live publishing.
